# Decision: implement Tranche 1 single-worker baseline

- Date: 2026-08-16
- Decision: **keep Tranche 2 forbidden**. The first T1 close was rejected (false provenance, dishonest crash counters, mixed campaign roots, in-process “canonical” reuse, unfair AFL++ lane). Those five blockers are now fixed. This is still **not** a public AFL++ comparison.
- Ground truth: `docs/MASTER_PLAN.md` §22 Tranche 1.

## Context

H0 is already accepted as a development gate (see `2026-08-16-h0-substrate.md`). Tranche 1 required:

1. Target manifests and build identities
2. Real in-process execution (already the H0 path)
3. Stable shared-memory edge coverage (already SanCov + `CoverageMap`)
4. Bounded persistent corpus
5. Honest crash / timeout / infra results (already `InfraError`)
6. Sanitizer replay and crash dedup
7. Canonical campaign artifacts and metrics
8. Microbenchmarks for execution correctness
9. Compare with LibAFL and AFL++ baselines

## Decision

- New crate `achlys-protocol` holds IDs, TOML manifests, `BuildIdentity`, and JSONL events. No LibAFL.
- Canonical coverage is a **post-campaign** replay (`CanonicalOracle` / `achlys_oracle`). The worker hot path is unchanged. Published edges come from the replay union, not the dirty worker map.
- Campaign artifacts use the Master Plan layout under a campaign root (`corpus/objects/ab/cd/<hash>`, `events/events.jsonl`, `metrics/summary.json`, `reports/canonical.json`).
- Sanitizer replay is a separate process with ASan/UBSan, stderr capture, process-group kill on timeout, and a normalized stack signature. Raw crash file count is not a metric.
- AFL++ gets a harness (`examples/targets/cJSON/harness_afl.c`) and `scripts/experiments/t1_compare.sh`. Missing `afl-fuzz` is a clean skip, not a fabricated number.

## Alternatives considered

- Putting canonical admission inside `run_substrate`. Rejected: that would put control-plane work on the hot path and break H0 comparability.
- Sharing `CoverageMap` as `Sync`. Rejected in Tranche 0; still rejected.
- Starting LLMP because “T1 is done”. Forbidden by the Master Plan.

## Expected consequence

A campaign can be reproduced from a manifest: same identity hashes, same content-addressed corpus, independently replayable coverage, verified crashes when candidates exist.

## Evidence required

- Unit/integration tests in protocol, store, oracle, sanitizer, micro.
- `T1_FUNCTIONAL=1 ./scripts/experiments/t1_smoke.sh` writes `canonical.json` and `events.jsonl`.
- H0 functional pair still passes.
- AFL++ numbers: only when `afl-fuzz` is present. This macOS host skipped AFL++.

## Remediation (same day)

| Blocker | Fix |
|---|---|
| Manifest did not select the harness | `WorkerTarget::parse` is mandatory; unknown `target_id` is a hard error. `cjson-parse` / listed micros each have their own linked or compiled harness. |
| Crash `verified` counted Clean | `CrashStats` splits candidates, unique, attempted, reproduced, signatures, clean, timeout, infra. `stack_signature` is only a stack. `dedup_key` is separate. Sanitizer compile failure is fatal. Stdin write errors are `InfraError`. |
| Reused `--out` mixed campaigns | `CampaignStore::create` and `achlys_t1` refuse a non-empty root. `campaign.json` records seed, budget, all three build identities, host, git. |
| Oracle reused the worker binary | Canonical and sanitizer binaries are compiled from the manifest flags, hashed, and recorded. Replay is a fresh dump process (`DumpOracle`). Every canonical event carries `canonical_build`. |
| AFL++ lane unequal | `t1_compare.sh` now uses the same `harness_afl.c`, `-O3`, `-G 64`, `-s`, `-t 1000`, `AFL_MAP_SIZE=65536`, and replays each corpus through `achlys_oracle`. Exec/s from unequal runs stay unpublished. |

CI smoke now checks `ingested == corpus == replayed`, `admitted+rejected == replayed`, target match, hex digest, occupied-root reject, unsupported-target reject, and an injected-clean-crash (`crash_files=1`, `clean=1`, `reproduced=0`).

`t1_compare.sh` compiles the canonical dump **once** and replays every executed lane against that same binary/`BuildId`. Replay failures are fatal unless `T1_RECORD_ONLY=1` marks the run incomplete.

## Later superseding decision

None. Linux multi-trial AFL++ vs Achlys vs LibAFL on the canonical dump remains required before any public coverage/time-to-target sentence.
